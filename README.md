# Nū — versions publiées

Ce dépôt public contient **uniquement les paquets publiés** de Nū, le
compagnon de bureau Nuprod. Le code source est dans un dépôt privé.

Chaque version est publiée automatiquement dans
[Releases](https://github.com/nuprod/nucompanion-release/releases). Les
applications installées détectent les nouvelles versions ici (`latest.json`)
et proposent de se mettre à jour.

## Installation

Télécharge le paquet de la [dernière version](https://github.com/nuprod/nucompanion-release/releases/latest) :

| Système | Fichier |
|---|---|
| Ubuntu 22.04 ou plus récent (amd64) | `Nuprod-Nu_<version>_amd64.deb` → `sudo apt install ./Nuprod-Nu_<version>_amd64.deb` |
| Windows 10 ou 11 (64 bits) | `Nuprod-Nu_<version>_x64-setup.exe` → double-clic (sans droits administrateur). Si SmartScreen s'affiche : *Informations complémentaires* › *Exécuter quand même* |
| macOS 11 ou plus récent (Intel et Apple Silicon) | `Nuprod-Nu_<version>_universal.dmg` → glisser Nū dans Applications |

Ensuite, Nū se met à jour tout seul : une bannière « Nouvelle version
disponible » apparaît, un clic suffit.
